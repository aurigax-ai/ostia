# Onboard

Your task starts with your role: worker, manager or reviewer. Read the step files of your role, in order, from `steps/` beside this file. Read only the step file you need now.

- worker: scout, name, worktree, test, pr, report, limits
- manager: name, issue, dispatch, watch, review, merge, cleanup, limits
- reviewer: review, report

- scout: read the issue, the code and the rules file
- name: register a bus name
- worktree: one worktree per task
- test: what to run before a push
- pr: push once, open the PR
- report: report by bus
- limits: what your role never does
- issue: write one issue per problem
- dispatch: start a worker with one short line
- watch: watch workers and PRs
- review: one focused review of a PR
- merge: when to merge
- cleanup: close tabs, remove worktrees
