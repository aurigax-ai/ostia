# Seams the tests name

- `ostia_agents::mail_delivery`: `MAIL_TURNS_MAX: usize`, `MAIL_TURNS_WINDOW_MS: i64`, `EVENT_BATCH_MS: i64`.
- `ostia_agents::mailers::{Mailers, MailerState}`: `Mailers::new(Clock)`, methods take `&self`, `MailerState { pub draft: bool }` with `Debug + PartialEq`.
- `ostia_agents::playbooks`: `PLAYBOOK_TEXT_MAX: usize`, `builtin_playbooks() -> &'static [BuiltinPlaybook]` with `pub description: String`. The markdown of `src/shared/agents/playbooks/` is copied into the crate and read with `include_str!`.
- `ostia_agents::playbook_enabled::playbook_enabled(&Value, &str) -> bool`. `undefined` is `Value::Null`.
- `ostia_agents::playbook_files`: `playbook_files(&Value, &[&str]) -> Vec<PlaybookFile>`, `PlaybookFile { id, description, skill: String, files: Vec<PlaybookExtraFile { path, text }> }`, `CurrentPlaybooks::{new, set(Value), current() -> Value, files(&[&str])}`. The TS module global is one `CurrentPlaybooks`.
- `ostia_contract::agent_stream`: `StreamEvent` and `StreamEnd` with `Serialize + Deserialize` in the TS wire shape (`#[serde(tag = "type")]`, kebab and dotted names), `Clone + Debug + PartialEq`. `StreamEnd` is `Copy + PartialEq + Debug`: `PaneClosed AgentClosed Unavailable OutOfScope TooSlow TooLarge`.
- `ostia_agents::stream_source`: `Emit = Arc<dyn Fn(Vec<StreamEvent>) + Send + Sync>`, `Backfill { pub events, pub truncated }`, `StreamSourceError`, trait `StreamSource { async fn backfill(&self, turns: usize) -> Result<Backfill, StreamSourceError>; fn live(&self, Emit); fn close(&self) }`.
- `ostia_agents::stream_pi`: `PiListener = Arc<dyn Fn(Vec<StreamEvent>) + Send + Sync>`, trait `PiStreamPort { fn subscribe(&self, PiListener) -> Box<dyn FnOnce() + Send + Sync>; fn snapshot(&self, usize) -> Vec<StreamEvent> }` (the `PiStream` of `src/main/agent` is not in this job), `pi_source(Arc<dyn PiStreamPort>) -> impl StreamSource`.
- `ostia_agents::stream_codex`: `CodexRequestError::new(impl Into<String>)`, trait `CodexRpc { fn request(&self, &str, Value) -> BoxFuture<'static, Result<Value, CodexRequestError>>; fn close(&self); fn closed(&self) -> BoxFuture<'static, ()> }`, `CodexNotice = Arc<dyn Fn(&str, &Value) + Send + Sync>`, `CodexConnect = Box<dyn Fn(CodexNotice) -> BoxFuture<'static, Result<Arc<dyn CodexRpc>, CodexRequestError>> + Send + Sync>`, `CodexSourceDeps { thread_id: String, connect: CodexConnect, closed: Box<dyn Fn(StreamEnd) + Send + Sync> }`, `codex_source(CodexSourceDeps) -> CodexSource` where `CodexSource: StreamSource`. `live` and `close` start timers with `tokio::spawn` and `tokio::time`, so they run inside a runtime.

- `ostia_agents::codex_rpc::connect_codex_rpc(&Path, &str, Option<CodexNotice>) -> Result<Arc<dyn CodexRpc>, CodexRequestError>` (async). A notice with no `params` gives `Value::Null`. The wire is a WebSocket over the unix socket. Tests serve it with dev-dependency `tokio-tungstenite` (workspace line added, version "0.28" unchecked: no registry copy here).
- `ostia_agents::codex_sockets`: `codex_socket_dir(&Host) -> Result<PathBuf>`, `codex_socket_path(&Host) -> Result<PathBuf>` (`<uuid>.sock`), `CodexSockets::{new, register(&str, PathBuf), socket_of(&str) -> Option<PathBuf>, forget(&str)}`. The TS module global is one `CodexSockets`.
- `ostia_agents::extension_agents`: `offer_text/offer_label/agent_prompt/agent_name/workspace_id_of(&Value) -> Option<String>`, `workspace_folder(Option<&str>, &Path) -> Option<PathBuf>`, `agent_task_limiter(Clock) -> ostia_diagnostics ReportLimiter` (the test reads `.take(key).allowed`), `AGENT_TASKS_PER_MINUTE: usize`, `REACHED_PANES_MAX: usize`, `HeldResume { pub resume: AgentResume, pub held: bool }`, `continue_command(&HeldResume, &str) -> String`. `continue_command` needs `can_fork`, `fork_command` and `resume_command` in `ostia_contract::agent_resume` (not there yet; `AgentResume` has no `typed`). `AgentOfferDelivery` is already in `agent_offer_relay`. The limiter type lives in `ostia-diagnostics`, so `ostia-agents` needs that dependency or a `Clock`-based copy.
- `ostia_agents::mail_flag::MailFlags::{new, register(&str, impl Into<PathBuf>), forget(&str), sync(&HashMap<String, usize>)}`. `sync` returns `()`. The sequence is a field of one `MailFlags`.
- `ostia_agents::mail_pending`: `PaneFacts { agent: Option<String>, agent_state: Option<String>, hibernated: bool, kind: Option<String> }` with `Default`, `MailerFacts { state: Option<MailerState>, limited: bool }` with `Default`, `mail_pending(Option<&PaneFacts>, impl Fn(&str) -> bool, MailerFacts) -> MailPending` (`MailPending` from `bus_store`).
